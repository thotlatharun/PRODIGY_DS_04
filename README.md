# 🧠 Social Media Sentiment Analysis

This project analyzes and visualizes sentiment patterns in social media data using Python, TextBlob, and NLP techniques.

## 📊 Features
- Clean and preprocess text data
- Perform sentiment analysis (Positive, Negative, Neutral)
- Visualize sentiment distribution with Seaborn
- Generate word clouds for each sentiment

## 🧰 Tech Stack
Python | Pandas | TextBlob | Seaborn | Matplotlib | WordCloud | NLTK

## 📈 Results
- Extracted overall sentiment trends from tweets
- Visualized public opinion patterns for various topics

## 📂 Dataset
(Dataset from Prodigy InfoTech](https://github.com/Prodigy-InfoTech/data-science-datasets/tree/main/Task%204)
